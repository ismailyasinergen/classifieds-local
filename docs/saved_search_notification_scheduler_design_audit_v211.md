## Scheduler design audit

Scheduler design is owner-scoped and opt-in only.

The future saved-search notification scheduler should:

- Select only saved searches where email notifications are enabled.
- Scope notification work to the saved-search owner.
- Exclude disabled saved-search notifications.
- Record when a saved search was checked.
- Record when a saved search notification was sent.
- Avoid duplicate sends by using timestamp and result-change logic.
- Keep notification work idempotent.
- Keep email behavior explicit and testable.
- Keep the local-only deployment model intact.

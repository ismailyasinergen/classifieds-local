# v190 Category Navigation Visual Polish and Accessibility

V190_CATEGORY_NAVIGATION_VISUAL_ACCESSIBILITY_POLISH

## Purpose

v190 improves the public browse category navigation partial with lightweight visual polish and accessibility semantics while preserving v186/v187/v188/v189 behavior.

## Repair 1 note

The initial v190 patch preserved the existing `aria-label="Category navigation"` attribute because its helper only added missing attributes. Repair 1 restores the partial and repatches it with deterministic attribute replacement so the navigation landmark uses `aria-label="Browse categories"`.

## What v190 changes

- Adds an accessible navigation landmark to the category navigation partial.
- Replaces the generic category navigation label with `aria-label="Browse categories"`.
- Adds a visible heading: "Browse by category".
- Adds helper copy explaining that category changes preserve current search and sort choices.
- Adds focus-visible styling hooks for keyboard users.
- Adds visual shell classes for spacing, border, radius, and mobile-friendly layout.
- Keeps the v186 category navigation marker and URL behavior intact.

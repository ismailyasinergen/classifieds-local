# v226 Saved Search Notification Admin UX Surfacing

V226_SAVED_SEARCH_NOTIFICATION_ADMIN_UX_SURFACING

## Purpose

v226 adds Django admin UX surfacing for saved-search notification state after the v225 production-delivery design audit checkpoint.

This checkpoint makes notification readiness visible to staff/admin users without adding delivery controls, rollback controls, scheduler automation, or production email behavior.

## What v226 adds

v226 updates the SavedSearch Django admin surface with:

- Saved-search label column.
- Owner column.
- Notification status column.
- Recipient email column.
- Last checked column.
- Last sent column.
- Notification enabled list filter.
- Search by name, querystring, owner username, and owner email.
- Read-only delivery readiness helper.
- Read-only timestamp display helpers.
- Legacy Email alerts preference column preservation.
- Legacy combined notification status text such as `Enabled, never checked` preserved.
- Legacy enable/disable email notification preference actions preserved.

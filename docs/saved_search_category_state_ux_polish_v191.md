# v191 Saved Search UX Wording and Category-State Polish

V191_SAVED_SEARCH_CATEGORY_STATE_UX_POLISH

## Purpose

v191 improves wording around category-aware saved searches on the public listing browse page while preserving v188 saved-search behavior and keeping seller-store templates untouched.

## What v191 changes

- Adds a category-specific saved-search note on public listing browse when a `category` query parameter is active.
- Clarifies that saving the search keeps the selected category together with current keywords and sort order.
- Adds a small accessible note region with `role="note"` and an explicit `aria-label`.
- Keeps the note hidden on default/non-category browse states.
- Keeps v188 saved-search category behavior untouched.

## Scope boundaries

- SavedSearch model fields.
- Saved search views.
- Saved search URLs.
- Seller-store models/views/templates.
- Category seed files.
- Category navigation Python utilities.

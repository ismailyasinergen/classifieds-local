# v221 Saved Search Notification Scheduler Email Dry-Run Integration

V221_SAVED_SEARCH_NOTIFICATION_SCHEDULER_EMAIL_DRY_RUN_INTEGRATION

## Purpose

v221 integrates the saved-search notification scheduler with the v218 email renderer behind explicit dry-run defaults.

This checkpoint adds email preview rendering only. It does not add real email delivery.

## What v221 adds

v221 adds scheduler helpers that can build saved-search email previews:

- `build_saved_search_notification_email_dry_run_preview`
- `build_saved_search_notification_scheduler_email_previews`

v221 also adds a management command flag:

- `--render-email-previews`

The flag is explicit and dry-run only.

## Safety behavior

The v221 preview path:

- Requires explicit operator action through the preview flag.
- Returns dry-run previews only.
- Shows recipient email.
- Shows rendered subject.
- Shows rendered text body.
- Shows rendered HTML body.
- Shows saved search id.
- Shows match count.
- Keeps delivery disabled.
- Keeps sent count at zero.
- Requires a future explicit execute gate for real delivery.
- Rejects disabled saved searches.
- Keeps owner-scoped and opt-in-only preview selection.
- Does not mutate checked timestamps.
- Does not mutate sent timestamps.
- Does not call Django mail delivery.
- Does not add a sender module.
- Does not add a background worker.

## What v215 implements

- A SellerStore admin action named `v215_export_selected_seller_stores_for_review`.
- The action exports selected SellerStore rows to CSV for manual review.
- The action is view-permission gated.
- The action removes the destructive `delete_selected` action from SellerStore admin actions.
- The action rejects empty selections.
- The action limits exports to 250 rows.
- The action escapes spreadsheet-formula prefixes in CSV values.
- The action does not approve stores.
- The action does not verify stores.
- The action does not suspend stores.
- The action does not delete stores.
- The action does not mutate SellerStore rows.

## Safety behavior

The v215 action is deliberately read-only.

It gives staff a safe way to export selected seller stores for review without changing status, verification, approval, suspension, or deletion state.

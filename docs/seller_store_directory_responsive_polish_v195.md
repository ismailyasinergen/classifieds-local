# v195 Seller Store Directory Responsive Polish

V195_SELLER_STORE_DIRECTORY_RESPONSIVE_POLISH

## Purpose

v195 improves responsive and mobile clarity for the seller-store directory while preserving saved-search management and public category navigation behavior.

## What v195 changes

- Adds a seller-store directory responsive guidance panel.
- Clarifies how users can combine search, category, location, sorting, and pagination.
- Adds responsive CSS hooks for a three-column desktop guidance layout.
- Collapses the guidance layout to a single-column reading flow on smaller screens.
- Preserves the existing v192 seller-store category-state note.
- Keeps saved-search management copy from v194 untouched.
- Keeps public category navigation keyboard/a11y behavior from v193 untouched.

## Scope boundaries

v195 intentionally does not change:

- SellerStore models.
- Seller-store views.
- Seller-store URLs.
- Seller-store category filtering behavior.
- Saved-search models/views/templates.
- Public listing browse template.
- Public category navigation partial.
- Category seed files.

## Guardrails

- No migrations should be generated by v195.
- backend/docs/ must not be recreated.
- v192/v193/v194 compatibility tests must remain green.
- Existing seller-store compatibility tests must remain green.
- Existing saved-search regression tests must remain green.
- Existing category navigation tests must remain green.
- Category-navigation and saved-search management templates must not receive v195 hooks.
- Full regression must pass before commit/tag.

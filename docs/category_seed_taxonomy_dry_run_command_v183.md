# v183 Category Seed Taxonomy Plan and Dry-Run Command

V183_CATEGORY_SEED_TAXONOMY_DRY_RUN_COMMAND

## Purpose

v183 introduces seed infrastructure for marketplace categories without immediately inserting a large production taxonomy.

The checkpoint adds:

- A small pilot taxonomy plan.
- Validation for duplicate slugs, missing parents, and maximum depth.
- A dry-run-first management command.
- An explicit --apply mode for writing categories.
- Idempotency tests proving repeated apply runs do not duplicate rows.

## Pilot taxonomy shape

The v183 pilot plan contains:

- 5 main categories.
- 10 sub-categories.
- 20 sub-sub-categories.
- Maximum depth: 3.

This is intentionally small. The goal is to validate the seed machinery before expanding into a full marketplace taxonomy.

## Command

Dry run:

    docker compose exec web python manage.py seed_marketplace_categories

Apply in the current database:

    docker compose exec web python manage.py seed_marketplace_categories --apply

## Guardrails

- The command defaults to dry-run.
- No listing UI, filter, saved search, or seller store behavior is changed in v183.
- No migrations should be generated by v183.
- backend/docs/ must not be recreated.
- Full regression must pass before commit/tag.

# v193 Category Navigation Keyboard/A11y Deepening

V193_CATEGORY_NAVIGATION_KEYBOARD_A11Y_DEEPENING

## Purpose

v193 deepens keyboard and screen-reader support for the public category navigation while preserving v190/v191/v192 behavior.

## What v193 changes

- Adds an explicit screen-reader-only keyboard help paragraph inside the public category navigation.
- Adds `aria-labelledby` and `aria-describedby` relationships to the category navigation landmark.
- Gives the visible "Browse by category" heading a stable ID.
- Adds a stable help-text ID for assistive technologies.
- Adds a dedicated v193 keyboard-ready CSS hook.
- Strengthens focus-visible styling for category links.
- Keeps the existing v190 `aria-label="Browse categories"` contract intact.

## Scope boundaries

v193 intentionally does not change:

- Category models.
- Category seed files.
- Category navigation Python utilities.
- Public listing browse template behavior.
- Saved-search models/views/templates.
- Seller-store models/views/templates.
- Seller-store directory UI from v192.

## Guardrails

- No migrations should be generated by v193.
- backend/docs/ must not be recreated.
- v190/v191/v192 compatibility tests must remain green.
- Existing saved-search regression tests must remain green.
- Existing seller-store compatibility tests must remain green.
- Seller-store templates must not receive the public category navigation tag or v193 hooks.
- Public listing browse and seller-store templates must remain untouched by v193.
- Full regression must pass before commit/tag.

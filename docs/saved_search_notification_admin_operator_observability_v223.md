# v223 Saved Search Notification Admin / Operator Observability

V223_SAVED_SEARCH_NOTIFICATION_ADMIN_OPERATOR_OBSERVABILITY

## Purpose

v223 adds read-only admin/operator observability for the saved-search notification system after the guarded v222 explicit-send checkpoint.

This checkpoint does not expand delivery behavior. It gives operators a safe way to inspect notification readiness and state before future operational improvements.

- Current base before v223: `f42b673`

## What v223 adds

v223 adds:

- `listings.saved_search_notification_observability`
- `build_saved_search_notification_observability_snapshot`
- `format_saved_search_notification_observability_lines`
- Management command flag: `--notification-observability-report`

## Observability report contents

The read-only report shows:

- Total saved searches in scope.
- Enabled notification count.
- Disabled notification count.
- Enabled searches with recipient email.
- Enabled searches missing recipient email.
- Checked timestamp count.
- Sent timestamp count.
- Sample saved-search rows.
- Recipient email visibility for operator review.
- Owner id visibility for operator review.
- Saved-search labels for operator review.

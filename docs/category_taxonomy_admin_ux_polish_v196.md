# v196 Category Taxonomy Admin UX Polish

V196_CATEGORY_TAXONOMY_ADMIN_UX_POLISH

## Purpose

v196 improves the Django admin experience for category taxonomy management while preserving the existing v182/v185 admin field contract.

## Repair note

The first v196 attempt failed safely because it changed Category admin `list_display`, which broke the v182 hierarchy safeguards and the v185 seed verification command's `Admin fields OK` check. It also attached helper functions as ModelAdmin methods without `self`, causing bound-method TypeErrors.

Repair 1 keeps the existing admin field contract intact and only adds safe helper methods and non-field admin UX options.

## What v196 changes

- Adds safe Category admin helper methods:
  - `v196_parent_path`
  - `v196_child_count`
  - `v196_status_label`
- Preserves the existing `list_display = ("name", "slug", "parent")` contract.
- Preserves existing list filters and search fields.
- Adds safe admin UX options:
  - `list_select_related` for `parent`
  - `list_per_page = 50`
  - `save_on_top = True`
  - `actions_on_top = True`
  - `show_full_result_count = False`
  - `preserve_filters = True`
- Keeps model/schema and seed data unchanged.

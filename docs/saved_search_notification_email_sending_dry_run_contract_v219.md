## Contract

A future saved-search notification sender must default to dry-run mode.

In dry-run mode it must:

- Build the same rendered preview returned by the v218 renderer.
- Include recipient email.
- Include rendered subject.
- Include rendered text body.
- Include rendered HTML body.
- Include saved search id.
- Include match count.
- Report that no email would be delivered.
- Avoid touching Django mail delivery.
- Avoid mutating `last_notification_sent_at`.
- Avoid mutating `last_notification_checked_at`.

A future real-send path must require an explicit execute flag or equivalent operator confirmation.

## Required safety rules

The future sender must remain:

- Owner-scoped.
- Opt-in-only.
- Disabled-search rejecting.
- Dry-run by default.
- Explicit-send only.
- Observable before delivery.
- Safe from accidental timestamp mutation.

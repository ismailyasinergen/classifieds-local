# v186 Category Navigation and Listing Filter Integration

V186_CATEGORY_NAVIGATION_LISTING_FILTER_INTEGRATION

## Purpose

v186 introduces safe category navigation and listing-query integration now that the expanded taxonomy has been seeded and verified locally.

## What v186 adds

- Category navigation context builder for the 3-level taxonomy.
- Descendant-aware category filtering utility for Listing querysets.
- Category filter URL builder that preserves search/sort state and drops stale pagination.
- Template tag and reusable partial for category navigation rendering.
- Tests proving root, child, and grandchild filtering works against Listing querysets.
- Tests proving invalid category slugs are safe and non-destructive.

## Scope boundaries

v186 does not redesign the full browse page layout yet.

The checkpoint provides the reusable integration layer that later browse-page UI checkpoints can mount into the existing templates safely.

## Guardrails

- No category seed files are changed.
- No listing model, listing form, saved search, or seller store behavior is changed.
- No migrations should be generated by v186.
- backend/docs/ must not be recreated.
- Full regression must pass before commit/tag.

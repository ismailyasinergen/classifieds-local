## What v214 implements

- A saved-search notification scheduler helper module.
- A local management command: `process_saved_search_notifications`.
- Default dry-run execution.
- Optional `--execute` mode for recording check timestamps.
- Optional `--limit` support.
- Opt-in-only candidate selection.
- Disabled saved-search notifications are excluded.
- `last_notification_checked_at` is recorded only in execute mode.
- `last_notification_sent_at` is not changed.
- Email sending is intentionally not implemented in v214.

## Safety behavior

The v214 command is deliberately conservative.

Default dry-run command:

    python manage.py process_saved_search_notifications

Execute mode for recording scheduler check timestamps locally:

    python manage.py process_saved_search_notifications --execute

This still does not send email.

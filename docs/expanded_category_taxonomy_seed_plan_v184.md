# v184 Expanded Category Taxonomy Seed Plan

V184_EXPANDED_CATEGORY_TAXONOMY_SEED_PLAN

## Purpose

v184 expands the category seed infrastructure after the v183 pilot.

v183 remains unchanged and continues to represent the 35-category pilot plan. v184 adds a separate expanded taxonomy plan and a separate dry-run-first command.

## Expanded taxonomy shape

The v184 expanded plan contains:

- 10 main categories.
- 30 sub-categories.
- 60 sub-sub-categories.
- 100 total categories.
- Maximum depth: 3.

## Command

Dry run:

    docker compose exec web python manage.py seed_marketplace_categories_expanded

Apply in the current database:

    docker compose exec web python manage.py seed_marketplace_categories_expanded --apply

## Guardrails

- The command defaults to dry-run.
- v183 pilot files are left unchanged.
- v184 uses a separate command instead of changing the v183 command behavior.
- No listing UI, filter, saved search, or seller store behavior is changed in v184.
- No migrations should be generated by v184.
- backend/docs/ must not be recreated.
- Full regression must pass before commit/tag.
